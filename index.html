¿Qué es?

Una app de escritorio pensada para el día a día del taller

Construida con Java Swing y patrón DAO sobre MySQL, sigue un flujo de trabajo cómodo: el operario inicia sesión y puede dar de alta clientes, registrar la entrada de un vehículo, gestionar productos en stock, cobrar reparaciones con desglose de subpagos y emitir facturas en PDF con JasperReports.

Módulos funcionales

Cinco verticales, una sola aplicación

Cada vertical sigue el mismo patrón: Crear, Modificar, Eliminar, Mostrar.

👥

Empleados

Solo accesible para JEFE
  • Alta con rol (JEFE / EMPLEADO)
  • Modificación y baja por usuario
  • Listado con último login formateado
  • Hash automático de contraseña al crearse
  • Autocompletado de usuarios para edición
🧑‍🤝‍🧑

Clientes

Accesible para todos los empleados
  • Datos: DNI, teléfono, email, apellidos

  • Autocompletado de DNI con popup

  • JOIN con cliente para evitar query N+1

Productos

Inventario del taller
  • Categorías: FLUIDOS, PIEZAS, NEUMÁTICOS, CONSUMIBLES, ACCESORIOS, RECAMBIOS, OTROS
  • Precio de compra y de venta
  • Gestión de stock incremental (cambiarStock)
  • Diálogo unificado “Gestionar” con sugerencias
💳

Pagos & Informes

Núcleo financiero
  • Tipo ENTRADA / SALIDA, método TARJETA / EFECTIVO / OTRO

Autenticación & permisos

Inicio de sesión seguro y separación de roles

El login se gestiona en JDialogLogin. La verificación se hace contra empleado.contrasenya usando Hash.verificarConSalt; si la contraseña almacenada todavía está sin salt, se valida con SHA-512 plano y se migra automáticamente al nuevo formato.

JEFE acceso total

Puede operar sobre cualquier entidad del sistema, incluida la gestión del personal y la importación masiva de datos.

  • Crear, modificar y eliminar empleados
  • Crear, modificar y eliminar clientes
  • Importar / eliminar datos de prueba (JSON · XML)
  • Generar informes en PDF
  • Todo lo del rol EMPLEADO

EMPLEADO operativa diaria

Foco en lo que ocurre en planta: clientes nuevos, vehículos que entran, productos vendidos y cobros del día.

  • Crear y modificar clientes
  • Crear, modificar y eliminar vehículos
  • Gestionar productos y stock
  • Registrar pagos y subpagos
  • No puede crear / borrar empleados
  • No puede importar datos masivamente

Importación & eliminación masiva

Carga el taller entero desde un solo archivo

La clase Importador acepta archivos JSON o XML con secciones empleados, clientes, productos, vehiculos y pagos. Cada operación se ejecuta dentro de una transacción: si algo falla, rollback de todo.

📄 datos_prueba.json (extracto)
{
  "empleados": [
    { "nombre": "Ana", "usuario": "ana",
      "contrasenya": "1234", "rol": "JEFE" }
  ],
  "clientes": [
    { "dni": "12345678A",
      "nombre": "Pedro",
      "apellido1": "García" }
  ],
  "vehiculos": [
    { "matricula": "1234ABC",
      "marca": "Seat",
      "dniCliente": "12345678A",
      "estado": "PENDIENTE" }
  ],
  "productos": [...],
  "pagos": [...]
}

Cómo funciona el Importador

1Detecta el formato.json → Gson · .xml → JAXP DOM
2Inserta en ordenempleados → clientes → productos → vehiculos → pagos
3Resuelve FKscliente.dni → clienteId al insertar vehículo
4Hashea passwordsAplica salt automáticamente a empleados
5Eliminación inversaBorra pagos → uniones → vehículos → productos → clientes → empleados
6Transaccionalcommit final · rollback si algo falla

🔐 Hash con salt — extracto de Hash.java
public String hashConSalt(String password) throws Exception {
  byte[] saltBytes = new byte[16];
  new SecureRandom().nextBytes(saltBytes);
  String salt = HexFormat.of().formatHex(saltBytes);

  MessageDigest md = MessageDigest.getInstance("SHA-512");
  md.update((salt + password).getBytes(UTF_8));

  return salt + ":" + HexFormat.of().formatHex(md.digest());
}
